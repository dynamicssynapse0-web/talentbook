Suppression de compte FamillySport

Cette page permet aux utilisateurs de FamillySport de demander la suppression de leur compte et des données personnelles associées.

Comment demander la suppression de votre compte

Pour demander la suppression de votre compte FamillySport, envoyez un e-mail à l'adresse suivante :

Email : dynamicssynapse0@gmail.com

Objet recommandé : Suppression de mon compte FamillySport

Dans votre demande, veuillez indiquer l'adresse e-mail utilisée pour votre compte FamillySport afin que nous puissions identifier le compte concerné.

Données supprimées

Après vérification de la demande, les données personnelles associées au compte seront supprimées ou rendues anonymes lorsque cela est techniquement possible.

Les données pouvant être supprimées comprennent notamment :

  • le prénom et le nom ;
  • l'adresse e-mail ;
  • le numéro de téléphone et le numéro WhatsApp ;
  • la photo de profil ;
  • les informations de localisation du profil ;
  • les informations professionnelles ou sportives ;
  • les photos et informations ajoutées au profil ;
  • les données associées au compte.

Données pouvant être conservées

Certaines informations peuvent être conservées lorsque leur conservation est nécessaire pour respecter une obligation légale, résoudre un litige, prévenir la fraude ou assurer la sécurité du service.

Ces données sont conservées uniquement pendant la durée nécessaire à la finalité concernée.

Délai de traitement

Les demandes de suppression sont traitées dans un délai raisonnable après vérification de l'identité et du compte concerné.
